# SouJunior — Apoia.se 🌱

Landing page desenvolvida para o **Hackathon SouJunior 2026**, com foco na campanha de apoio recorrente da comunidade no [Apoia.se](https://apoia.se/soujunior).

## 🎯 Objetivo

Contar a história da SouJunior, mostrar transparência no uso do dinheiro arrecadado e incentivar doações recorrentes a partir de **R$ 2,00**, mantendo a comunidade gratuita e acessível para quem está começando na programação.

## ✅ Requisitos do MVP atendidos

- **Hero com CTA principal** — proposta de valor direta e botão de apoio ligado ao Apoia.se
- **Motivo do apoio (transparência)** — explicação de para onde vai o dinheiro, com breakdown visual animado por categoria
- **Mural de dados/impacto** — números da comunidade (devs, mentores, eventos)
- **CTA e benefícios do apoio** — três planos recorrentes a partir de R$ 2, com plano em destaque
- **Integração com o ecossistema** — links diretos para Discord, WhatsApp e GitHub

## 👥 Personas atendidas

- **Apoiador(a) / comunidade** — caminho direto para os planos de doação
- **Voluntário(a) / mentor(a)** — chamada para entrar no Discord e se envolver com mentoria
- **Empresa / patrocinador** — chamada específica voltada a patrocínio institucional

## ✨ Diferenciais

- Navegação com transição animada entre seções e item de menu ativo destacado
- Barras de transparência animadas, mostrando a distribuição real do valor arrecadado
- Depoimentos de três perspectivas da comunidade (mentorado, apoiadora, mentor sênior)
- Suporte a `prefers-reduced-motion` e layout 100% responsivo
- Identidade visual própria — paleta escura com violeta e verde-limão, tipografia Space Grotesk + IBM Plex Mono

## 🛠️ Tecnologias

HTML, CSS e JavaScript puro — sem frameworks ou dependências externas de build. Um único arquivo (`index.html`), leve e fácil de rodar em qualquer lugar.
